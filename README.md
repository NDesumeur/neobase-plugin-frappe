# Test de frappe

Teste et améliore ta vitesse de frappe au clavier dans NeoBase : modes au temps ou au nombre de
mots, ponctuation en option, retour lettre par lettre et historique de tes scores.

## Installer

Dans NeoBase : **NeoStore → À découvrir → Test de frappe → Installer**.

Développer un plugin : voir le [SDK NeoBase](https://github.com/NDesumeur/neobase-sdk).
